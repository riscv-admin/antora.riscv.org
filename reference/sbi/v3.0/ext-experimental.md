# 21.1. Experimental SBI Extension Space (EIDs #0x08000000 - #0x08FFFFFF)

## [](#21-1-experimental-sbi-extension-space-eids-0x08000000-0x08ffffff)21.1\. Experimental SBI Extension Space (EIDs #0x08000000 - #0x08FFFFFF)

The SBI specification doesn’t define any rules for the EID management for experimental SBI extensions.
