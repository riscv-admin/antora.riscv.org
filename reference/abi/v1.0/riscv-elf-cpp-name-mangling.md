# 7.1. C&#43;&#43; Name Mangling

## [](#7-1-c-name-mangling)7.1\. C++ Name Mangling

C++ name mangling for RISC-V follows the _Itanium C++ ABI_ [\[itanium-cxx-abi\]](#itanium-cxx-abi); there are no RISC-V specific mangling rules.

See the "Type encodings" section in _Itanium C++ ABI_for more detail on how to mangle types.
