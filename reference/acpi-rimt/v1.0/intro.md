# 1.1. Introduction

## [](#1-1-introduction)1.1\. Introduction

The RISC-V IO Mapping Table (RIMT) provides information about the RISC-V IOMMU \[[1](bibliography.html#bib-iommu-spec)\] and the relationship between the IO topology and the IOMMU in ACPI \[[2](bibliography.html#bib-acpi-spec)\] based RISC-V platforms. The RIMT identifies which components are behind IOMMU and how they are connected together. RISC-V IOMMU can be implemented as either a PCIe device or a platform device.
